# 公开数据说明

本仓库用于个人作品集展示，是原本地项目的独立公开副本。

- 原始评论与人工 Gold Excel 的 `用户名` 数据已清除，包括对应的不再使用的 XLSX 共享字符串；保留表头以兼容读取逻辑。
- 82 条评论的 ID、产品、评论原文、其余来源信息、人工标签与复核信息均保留。已逐单元格核对除用户名外的值与本地原件一致。
- Prompt 快照、历史模型预测、Evaluation 指标、E1/E2 证据链和 Langfuse 实验回执保持原样。没有为发布重新调用模型或重跑实验。
- 公开 Gold 文件因脱敏而具有新的 SHA-256。`evaluation/results/experiment_evidence_manifest.json` 的文件清单记录公开文件哈希，`publication` 元数据保留原始 Gold 哈希和变更原因；其他列入清单的证据哈希不变。
- 本地原件与凭据不在此仓库。`.env`、虚拟环境、缓存、临时输出及新用户批次目录不会提交。
- 评论来源于已采集的公开评论；小样本结果不代表总体用户或市场。原文可能包含用户自行描述的设备和工作场景，请勿将其当作已验证的用户画像。

## 本地启动

按照 README 安装依赖后执行 `streamlit run app.py`。页面默认离线展示项目证据，新评论分析默认 Mock。无需配置密钥即可进行演示。

运行真实模型、Evaluation 或 Langfuse 脚本需要单独配置个人凭据，并可能产生外部调用。不要把真实密钥写进源代码或提交到 GitHub。
