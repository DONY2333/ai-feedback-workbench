# 简历素材

目标岗位：AI 产品经理 / AI 产品实习生。个人项目，未正式上线。

## A. 推荐正式版

- 围绕非结构化用户反馈，设计「清洗—LLM 结构化—问题归并—需求建议」流程，保留原始 ID 与证据链，区分用户事实和产品推断。
- 基于 Python、pandas、LLM API 与 Streamlit 实现四页本地工作台，支持反馈筛选、Issue 证据回溯、模型质量及竞品问题展示。
- 使用 82 条人工 Gold 划分 Dev 20 / Holdout 62，完成 V1→V3 迭代与 Langfuse 三版实验；V3 Holdout 类型准确率 87.10%，整条完全正确率 59.68%。
- 基于 63 条问题反馈，以保守离线规则形成 54 个候选 Issue、飞书/企微样本画像和 Top 5，并围绕 5 条通知证据产出 Mini PRD 与三帧原型规格。

## B. 一页简历压缩版

- 设计用户反馈到产品需求的分析流程，以原始 ID 保留反馈、Issue 与需求的证据链。
- 用 Python、pandas、LLM API、Streamlit 构建四页本地分析工作台。
- 基于 82 条 Gold 完成三版 Prompt 与 Langfuse 实验，V3 留出集类型准确率 87.10%。
- 从 63 条问题反馈提炼 Top 5，产出通知诊断 Mini PRD 和三帧原型规格。

## 表述边界

留出集已分析，历史 normalization 为 partial reproduction。54 个是候选，未全部深度复核。原型规格不是已绘制 Figma。未证明降本、收入或留存提升。[项目案例](project_case.md)保留具体限制。
